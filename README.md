## Обзор
Сервис предоставляет API для создания, чтения и обновления записей об угрозах. Данные хранятся в PostgreSQL. Реализована валидация входных данных, централизованная обработка ошибок, ограничение частоты запросов (rate-limit) и защита методов изменения через API-ключ.

## Технологический стек
- **Язык:** Go 1.22+
- **HTTP-роутер:** chi
- **База данных:** PostgreSQL 16
- **Драйвер БД:** pgx
- **Контейнеризация:** Docker, Docker Compose

## Требования
- Docker
- Docker Compose

## Быстрый старт

1. Скопируйте пример конфигурации:
```bash
cp .env.example .env
```
2. Запустите сервисы
```bash
docker compose up --build
```
3. Сервисы будет доступен по адресу:
```text
http://localhost:8080
```

## Использование API

Полная спецификация API доступна в файле [`api/openapi.yaml`](api/openapi.yaml).

### Создать угрозу (POST)
Для создания записи необходим заголовок `X-API-Key`.
```bash
curl -X POST localhost:8080/info \
  -H "Content-Type: application/json" \
  -H "X-API-Key: secret-key" \
  -d '{"md5":"d41d8cd98f00b204e9800998ecf8427e","name":"Trojan.Test","severity":"high","type":"trojan"}'
```
### Изменить угрозу (PUT)
Для изменения записи необходим заголовок `X-API-Key`.
```bash 
curl -X PUT localhost:8080/info/d41d8cd98f00b204e9800998ecf8427e \
  -H "Content-Type: application/json" \
  -H "X-API-Key: secret-key" \
  -d '{"name":"Trojan.Updated","severity":"critical","type":"ransomware"}'
```
### Получить угрозу (GET)
```bash 
curl -X GET localhost:8080/info/d41d8cd98f00b204e9800998ecf8427e
```

## Безопасность

В сервисе реализованы два механизма защиты:

### 1. Управление доступом (API-ключ)
Методы, изменяющие данные (`POST` и `PUT`), требуют наличия заголовка `X-API-Key`.
- Если ключ отсутствует или неверен, сервер возвращает `401 Unauthorized`.
- Метод чтения (`GET`) доступен без ключа.

### 2. Ограничение частоты запросов (Rate-limit)

Для защиты сервиса от спама и DDoS-атак настроен rate-limit: **не более 10 запросов в минуту с одного IP-адреса**.

Если клиент превышает лимит, сервер возвращает ошибку:
- **HTTP-код:** `429 Too Many Requests`

## Обработка ошибок

Все ошибки возвращаются в едином формате JSON:
```json
{
  "message": "Краткое описание ошибки",
  "details": "Дополнительная информация"
}
```
| Код | Название | Описание |
| :--- | :--- | :--- |
| `400` | Bad Request | Невалидный MD5 или поля запроса |
| `401` | Unauthorized | Отсутствует или неверный API-ключ |
| `404` | Not Found | Угроза с указанным MD5 не найдена |
| `409` | Conflict | Угроза с таким MD5 уже существует |
| `429` | Too Many Requests | Превышен лимит запросов |
| `500` | Internal Server Error | Внутренняя ошибка сервера |
